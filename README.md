# Library Desk

Lokale Suno-Prompt-Bibliothek als Electron-App.

## Start

```bash
npm install
npm run dev
```

Es öffnet sich ein Electron-Fenster (kein Browser-URL).

Weitere Skripte: `npm run build`, `npm test`, `npm run preview`.

## Workspace

Diesen Ordner (`suno-prompt-desk`) als eigenen Workspace öffnen — nicht den Elternordner „Cursor Projekte“. Beim Öffnen startet `npm run dev` über die VS-Code-Aufgabe.

# Web Desk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Browser-Version von Library Desk mit IndexedDB-`DeskApi`, leerem Start, eigener Bibliothek pro Nutzer/Browser, deploybares Static-Build.

**Architecture:** Gleiche React-UI; `window.desk` kommt im Web von einem IndexedDB-Adapter statt Preload/IPC. Entry-Filter/Sort als shared Pure Function. Cover/Audio als Blobs. Vite-Web-Target neben electron-vite.

**Tech Stack:** React 18, TypeScript, Vite, IndexedDB (idb oder natives IDB), Vitest (+ fake-indexeddb), bestehende shared Module

## Global Constraints

- Kein Login, kein Cloud-Sync in v1
- Eigene Bibliothek pro Browser (IndexedDB); Start leer
- DeskApi-Parität laut Spec `docs/superpowers/specs/2026-10-07-web-desk-design.md`
- Electron/Desktop unverändert nutzbar (`npm run dev`, `dist:mac`)
- Scripts: `dev:web`, `build:web`; Output `dist-web/` gitignored
- Shared Types/`exportFormat`/`mastermindImport` wiederverwenden; kein `better-sqlite3` im Web-Bundle
- Commits nur auf explizite Nutzerbitte
- Persistenz-Hinweis in der UI

- [ ] **Step 1: `vite.config.web.ts`**

```ts
import { resolve } from 'path'
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  root: '.',
  publicDir: 'public',
  define: { 'import.meta.env.VITE_DESK_WEB': JSON.stringify('true') },
  resolve: {
    alias: {
      '@shared': resolve('src/shared'),
      '@renderer': resolve('src/renderer'),
    },
  },
  build: {
    outDir: 'dist-web',
    emptyOutDir: true,
  },
  server: { port: 5174 },
})
```

`index.web.html` zeigt auf `/src/web/main.tsx`.

- [ ] **Step 2: `src/web/main.tsx`**

```ts
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from '@renderer/App'
import '@renderer/styles.css'
import { createWebDeskApi } from './deskApi'

async function boot() {
  const desk = await createWebDeskApi()
  ;(window as Window & { desk: typeof desk }).desk = desk
  ReactDOM.createRoot(document.getElementById('root')!).render(
    <React.StrictMode>
      <App />
    </React.StrictMode>,
  )
}

boot()
```
